🖱️ 마우스 조작 및 빠른 프리셋

  • 좌클릭 드래그 (배경): 선택된 도구(✏️ 펜 또는 ↗ 화살표)로 그리기 (👆 선택 모드에서는 객체 선택)
  • 우클릭 드래그 (배경): 화면 패닝 (지도 스크롤 이동)
  • 마우스 휠: 지도 확대/축소 (마우스 커서 위치 기준)
  • 좌클릭 / 드래그 (챔피언/오브젝트/획): 객체 단독 선택 및 위치 이동
  • 더블클릭 (배치된 챔피언): 팀 테두리 색상 순환 (⚪ 흰색 → 🔵 블루 → 🔴 레드)
  • 더블클릭 (정글 캠프/오브젝트): 처치·부재 표시용 반투명 토글
  • 우클릭 (챔피언/오브젝트/선): 컨텍스트 메뉴 오픈 (팀 테두리 선택, 화살표 추가/제거, 삭제)
  • 챔피언 목록 빠른 추가: 초성 검색(예: ㄹㅅ) 지원, 아이콘 더블클릭 → 아군 추가 / 우클릭 → 적군 추가

📱 모바일 / 터치 조작

  • 1손가락 드래그 (배경): 선택된 도구(✏️ 펜 / ↗ 화살표 / 🧼 지우개)로 그리기 (👆 선택 모드에서는 패닝)
  • 1손가락 드래그 (챔피언/오브젝트): 배치된 객체 위치 이동
  • 1손가락 탭 / 더블탭: 객체 단독 선택 / 정글 캠프 반투명 토글
  • 2손가락 핀치 / 드래그: 두 손가락 기준 확대·축소 및 화면 패닝

⌨️ 단축키

  • 1 / 2 / 3 / 4 : 👆 선택 / ✏️ 펜 / ↗ 화살표 / 🧼 지우개 도구 즉시 전환
  • C : 챔피언/오브젝트는 남기고 현재 스텝의 선과 화살표만 지우기
  • ← / → : 이전 / 다음 스텝 이동
  • Del / Backspace : 선택된 객체 삭제
  • Ctrl + Z : 실행 취소 (Undo)
  • Ctrl + Shift + Z / Ctrl + Y : 다시 실행 (Redo)

📋 스텝 · 전술 페이지 · 아이콘 크기

  • + Step 추가: 현재 배치를 이어받아 다음 스텝을 생성합니다. (선 지우지 않기 체크 시 그림 유지)
  • 이전 위치 잔상: 직전 스텝에서 이동한 챔피언의 원래 자리를 반투명 잔상과 이동 점선으로 함께 표시합니다.
  • 전술 페이지 (우측 팀/핑 하단): 전체 스텝과 배치를 저장·불러오기·수정·삭제할 수 있습니다.
  • 3종 아이콘 크기: 우측 하단에서 👤 챔피언 / ⚔️ 미니언 / 👾 오브젝트 크기를 개별 슬라이더로 조절할 수 있습니다.
  • 프리셋 기능: 챔피언을 드래그해서 배치하거나 아군/적군 프리셋 묶음을 전체 드롭하여 배치할 수 있습니다. (저장 시 Enter 지원)

🖼️ 스크린샷 모드 조작

  • 이미지 불러오기: 어느 모드에서든 이미지를 복사한 뒤 화면에서 Ctrl + V를 누르면 자동으로 스크린샷 모드로 전환되며 배경에 즉시 적용됩니다.
  • 스크린샷 관리: 좌측 상단의 [스크린샷] 탭에서 이미 저장된 목록을 확인하고 불러오거나, 이름 변경(✏️) 및 삭제(✖)를 할 수 있습니다.
